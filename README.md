# Gestão Oficina  Pro

vamos criar um site destinado a oficinas mecânica! teremos que ter o cadastro de serviço, preços, clientes, veículos, áreas de descrições extras para serviços e valores. tipo de pagamentos, esse sistema será destinado a vários estabelecimentos então teremos que ter uma base de cadastro para cada cnpj e em caso de mais de uma oficina com o mesmo cnpj, ter o acesso duplo porem separando os dados de cada endereço. teremos que ter uma área de ordem de serviço, cadastro de peças por nome/ lote e precificação ( nao obrigatório para cadastro lote e preço). teremos que ter tambem uma area de cadastro para o colaborador.

CRIAR A PAGIANA DE ADMINISTRADOR GERAL DO SISTEMA, ONDE O USOARIO QUE QUISER ULTILIZAR O SISTEMA TERA QUE SE CADASTRAR E TERA QUE PASSAR PELA APROVAÇÃO DESSE ADMINISTRADOR GERAL. COLOCAR FORMAS DE BLLOQUEAR TEMPORARIAMENTE O SISTEMA DO USUARIO ( BOTAO ´´ PLAY PAUSE``) OU PRE DEFINIDO POR DATA ( LIBERADO ACESSO ATE DIA DD/MM/AAAA)

LOGIN DE CADASTRO SEMPRE SERA O ADMINISTRADOR GERAL DO ESTABELECIMENTO. ONDE ELE CONVIDADARA OS DEMAIS COLABORADORES, MECANICOS, RECEPICIONISTAS.
